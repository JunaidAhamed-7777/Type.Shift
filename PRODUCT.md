# Type.Shift

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A free, account-free typing test using passages from literature, science, and programming. Measure words per minute, final-text accuracy, and elapsed time.

## Capabilities and Constraints

Four difficulties: easy, medium, hard, code. Random passages do not repeat until the category is exhausted. Tests finish when time expires or the passage is typed. Keep book-cover and source attribution, the credited Matrix result effect, legal documents, and code comments. React 19 / Create React App / plain CSS; no framework migration, backend, database, or authentication.

## Operating Context

Desktop keyboards and mobile touch keyboards. Tab restarts from an active typing input; keyboard users must also be able to leave the input and navigate all controls.

## Brand Commitments

Keep Type.Shift, Junaid's authorship, GitHub, and the personal-site link to https://junaidahamed.runs-on.dev. The user has delegated the visual direction and requested a substantial, distinctive redesign with desktop/mobile accessibility and frequent focused commits.

## Evidence on Hand

README.md, AGENTS.md, src/data/paragraphs.js, public/assets, public/legal. No invented customers, performance benchmarks, or account features.

## Accessibility & Inclusion

Keyboard navigation, named controls, readable contrast, reduced motion, dialog focus management, responsive reflow, and mobile input behavior are required by the user's brief.
